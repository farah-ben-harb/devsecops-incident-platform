# Security Policy

## Security expectations

- Never commit live secrets, tokens, certificates, or `.env` files.
- Keep example values in `.env.example` only.
- Use environment-specific credentials outside Git.

## Reporting a vulnerability

If you find a security issue:

1. Do not publish exploit details in a public issue.
2. Describe the affected file, workflow, or endpoint.
3. Include enough context to reproduce safely.
4. Do not paste secret values into the report.
